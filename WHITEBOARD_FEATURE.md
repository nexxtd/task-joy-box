# Whiteboard Feature Documentation

## Overview
The Whiteboard feature is a flexible canvas-based workspace that allows users to visually organize ideas, tasks, and projects. It provides a variety of tools to create and connect different types of content in a free-form environment.

## Features

### Left Sidebar Tool Selector
The whiteboard includes a fixed vertical sidebar on the left side of the canvas that remains visible at all times. The sidebar contains:

- Vertical stack of tool icons in one column
- Even spacing between tools
- Simple icons with optional labels or hover tooltips
- Soft background that blends into the canvas
- Active tool state with highlighted icon and subtle glow

### Available Tools

#### 1. Selection Tool
- Allows selecting, moving, and manipulating existing items
- Provides resize handles and toolbar when an item is selected

#### 2. Sticky Notes Tool
- Quick brainstorming and idea placement
- Click anywhere on canvas to create a sticky note
- Notes can be:
  - Dragged freely around the canvas
  - Resized from corners
  - Color-coded for organization
  - Connected to other items

#### 3. Text Section Tool
- Floating structured writing blocks
- Supports headings, paragraphs, lists, quotes, and code blocks
- Can be resized vertically or horizontally
- Connectable to other objects

#### 4. Document Block Tool
- Large structured canvas pages for complex content
- Supports long writing, tables, embedded files, and images
- Acts like a movable mini document
- Collapsible sections with draggable header

#### 5. Image Tool
- Place and organize images anywhere on the canvas
- Supports drag-and-drop, paste, and upload
- Images can be:
  - Resized, rotated, and cropped
  - Layered above or below items
  - Connected using arrows

#### 6. Connector & Arrow Tool
- Link everything together with various connection types
- Each object has hidden edge points that appear on hover
- Connection types: straight arrows, curved flows, elbow lines, dotted links
- Connections stay attached when moving objects

#### 7. Shapes Tool
- Diagram and layout builder with basic geometric shapes
- Includes rectangles, circles, triangles, and squares
- Shapes can hold text, change color, and connect to other items

#### 8. Task Block Tool
- Live task system connected to the main app
- Drag task blocks onto the canvas
- Tasks can be assigned, reordered, and given due dates
- Updates in real-time throughout the application

#### 9. Mindmap Tool
- Expandable idea system starting from one node
- Tab creates child nodes, Enter creates sibling nodes
- Nodes can link to other items on the canvas

#### 10. File Upload Tool
- Drag and drop files into the workspace
- Supports PDFs, documents, images, and other file types
- Files become movable blocks that can be connected to other items

## Usage

### Creating Items
1. Select a tool from the left sidebar
2. Click anywhere on the canvas to create an item
3. The newly created item will be automatically selected

### Manipulating Items
1. Click the Selection tool (arrow icon) in the sidebar
2. Click on any item to select it
3. Drag the item to move it around the canvas
4. Use corner handles to resize the item
5. Use the toolbar that appears when an item is selected for additional actions

### Connecting Items
1. Click the Connector tool (link icon) in the sidebar
2. Click on the connection point of one item
3. Click on the connection point of another item
4. A connection line will appear between the two items
5. The connection will move with the items when they are repositioned

### Deleting Items
1. Select the item you want to delete
2. Use the delete button in the toolbar that appears
3. Alternatively, press the Delete key on your keyboard

## Keyboard Shortcuts
- Delete: Delete selected item
- Ctrl+Z: Undo last action (coming soon)
- Ctrl+Y: Redo action (coming soon)

## Best Practices
- Use sticky notes for quick brainstorming
- Organize related items close to each other
- Use color coding to categorize different types of information
- Connect related concepts to visualize relationships
- Group similar tools together for efficient workflow
